# Design

This folder is the designer's space. `DESIGN.md` at the repo root is the design system and UX rules, and agents follow it for all UI work.

- `design/exports/`: exported screens (PNG or SVG) named `<card-name>-v<n>.png`.
- Source files can live in [Penpot](https://penpot.app) (open source) or Figma. Put the share link in the matching Notion card and in `DESIGN.md`.
